Rentora — Peer-to-Peer Car Rental Marketplace

Python Django PostgreSQL KYC Verification

The Challenge

Creating a trust-based marketplace where users feel safe renting expensive assets — vehicles — to and from peers they've never met.

The Solution

Integrated secure KYC-verified onboarding flows and a robust two-way rating system so renters and owners can vet each other before a booking. Used Django's atomic transactions throughout the booking pipeline to guarantee data integrity even under concurrent access.

Tech Stack

Django and PostgreSQL power the core marketplace logic, with schema design optimized for fast fleet search and filtering. Booking writes are wrapped in transaction.atomic() blocks to prevent partial or inconsistent state during high-concurrency periods.

System Architecture Flow

      graph TD

          Atomic -->|4. Lock Vehicle State & Billing| Postgres[(PostgreSQL B-Tree Database)]
          Postgres -->|5. Atomic Commit| Confirm[Rental Contract Confirmed]

Key Impact

100+ active fleet entries during beta, with zero reported data inconsistencies due to race conditions.
