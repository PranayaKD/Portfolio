Django PostgreSQL Rate Limiting Commercial Deployment Responsive UI

The Challenge

Replacing an informal, manual inquiry process for a growing private security agency with a production-grade web platform that routes service inquiries, prevents spam abuse, and presents credibility signals to high-value commercial clients.

The Solution

Built a modular Django backend with custom inquiry routing middleware, IP-based rate limiting to prevent form spam (token bucket algorithm), and a mobile-first responsive UI designed for trust — clear service taxonomy, testimonial placement, and streamlined contact funnels.

Backend Architecture

Django handles all routing, form validation, and inquiry persistence. Middleware intercepts and rate-limits repeated submissions per IP. Service categories are database-driven for easy admin expansion without code changes.

Key Impact

Successfully deployed as the agency's primary lead generation platform — processing 100+ monthly inquiries with zero spam penetration via token bucket rate limiting.
